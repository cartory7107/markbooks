# MarkBook AI Hub

Create a world-class, modern AI marketplace website called "MarkBook".

MarkBook is the world's AI discovery and research platform where users can explore, compare, and discover over 20,000 AI tools. The goal is to make AI research extremely easy for everyone.

IMPORTANT DESIGN PHILOSOPHY:

- Keep the design simple, premium, and professional.

- Use a clean white background with subtle grid patterns.

- Follow a modern social media style similar to Facebook's three-column layout.

- The design should feel like a billion-dollar startup.

- Add smooth animations, micro-interactions, hover effects, and subtle 3D/parallax effects.

- The UI should be fast, minimal, and not overloaded.

==================================================

HEADER / NAVIGATION

==================================================

Create a sticky top navigation bar.

Left side:

- Display the MarkBook black logo.

- Show the brand name "MarkBook".

Center:

- A large intelligent search bar:

  "Search 20,000+ AI tools..."

- Search should instantly suggest AI tools, categories, and keywords.

Right side:

- Navigation links:

  - Categories

  - Latest AI

  - Hidden Gems

  - Free AI

  - Research

  - Advertise

Add a beautiful dark/light mode switch.

==================================================

MAIN HOMEPAGE LAYOUT (Facebook Style)

==================================================

Create a three-column responsive layout.

LEFT SIDEBAR (Advertisement Area):

- Dedicated sponsored AI advertisements.

- Show premium AI tools promoted by companies.

- Display a small "Sponsored" label.

- Each ad card includes:

  - AI logo

  - AI name

  - Short description

  - Visit button

The advertisement cards must look premium and trustworthy.

--------------------------------------------------

CENTER CONTENT (Largest Section):

This is the heart of MarkBook.

SECTION 1: Latest AI Tools

- Display newly launched AI tools.

- The number should not be fixed to 10.

- Automatically display the newest available AI tools.

- Show:

  - AI logo

  - Name

  - One-line description

  - Category

  - Pricing (Free/Paid/Freemium)

  - Visit Website button

SECTION 2: Hidden AI Gems

- Show powerful but less popular AI tools.

- Help users discover underrated tools.

- Include a "Why this is useful" short explanation.

SECTION 3: Trending Free AI Tools

Create smart collections such as:

- Best free AI image generators

- Best free AI video generators

- Best free coding assistants

- Best free writing AI tools

- Best free productivity AI tools

SECTION 4: AI Research Assistant

Create a research section where users can ask:

Examples:

"I need a free AI that can generate videos."

"I need an AI for coding."

"I need an AI for creating presentations."

The system should analyze the user's need and recommend relevant AI tools with explanations.

AI TOOL DATABASE STRUCTURE

==================================================

Each AI tool profile should contain:

- Logo

- Name

- Official website URL

- Short description

- Detailed overview

- Main features

- Categories

- Pricing model

- Free plan availability

- Platform support

- Use cases

- Pros & Cons

- Popularity score

IMPORTANT DATA HANDLING:

The platform will receive thousands of AI names. Many entries may not include website links.

Create an intelligent AI enrichment system that can:

- Analyze the AI tool name.

- Find the correct official website URL.

- Fetch missing public information.

- Avoid incorrect or unofficial links.

- Allow manual verification before publishing.
